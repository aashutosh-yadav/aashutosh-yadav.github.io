Things I've built

URL Shortener

I built this to learn what "performance" actually means in practice. After a lot of load testing I got it to ~1900 requests per second at around 50ms latency. The interesting part wasn't the number — it was figuring out that worker contention was the bottleneck, not the database, which meant the Redis cache I added was actually making things slower. That was a useful lesson. — GitHub

Learnlense

An AI tool that takes a YouTube video or an MP4 and turns it into something useful — a summary, a mind map, a Q&A chatbot, and a few other things. It transcribes audio with Whisper and then passes that to LLaMA 3.3 70B. I also set up a fallback chain so if one provider is down it automatically tries the next one. Wrote a research paper on it too. — GitHub

REST API Backend

A fairly complete backend with user auth, posts, and the usual CRUD stuff. Built it to get a proper understanding of JWT, OAuth2, database migrations, and how to structure a FastAPI project beyond toy examples. — GitHub
