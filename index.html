High-Performance URL Shortener — GitHub
Python, FastAPI, PostgreSQL, Redis, Docker

Built a read-heavy backend to understand performance in practice. Got it to ~1900 req/sec at ~50ms latency under 100 concurrent users. The surprising finding: adding Redis made things slower because the database wasn't the bottleneck — worker contention was. Multi-worker scaling improved throughput ~6x. Load tested up to 500 concurrent users and mapped where the system saturates (~2500 RPS).
