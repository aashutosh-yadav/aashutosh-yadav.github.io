High-Performance URL Shortener — GitHub | README | Benchmarks | Live Demo

Python, FastAPI, PostgreSQL, Redis, asyncio

A fully async URL shortener with in-process LRU and Redis caching. Load testing exposed cache and thread-pool bottlenecks, which I fixed through cache-path optimization and a full async rewrite. Reached ~20,400 req/sec on cache hits and ~3,500 req/sec on cache misses. Metrics shown on the page are very different from the ones in the benchmarks because of deployment resources (free version); for real numbers, you can check it out locally.

Message queue -- GitHub

Go, , Redis, goroutines

A message queue built with Go and Redis. An API takes messages and replies right away, and 5 workers process them in the background. Messages are kept until they are done, so they are not lost if a worker crashes, and failed messages are retried up to 3 times before going to a failed-messages list.
